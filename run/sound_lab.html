Crucible Sound Lab

Dependency-free Web Audio patch workbench. Tweak, test, randomize, then copy the patch JSON back into your one-file sandbox goblin.

Patch Controls

Audio is locked. Click Enable Audio once. Browsers require a user gesture before sound can start.

The universal instrument is: tone layer + noise layer → envelope → filter → optional distortion → compressor. Some presets sound best with mostly noise; others with mostly tone. The random width controls how much each play varies.

Output / Meter

“Burst x8” simulates many pixel events being aggregated into a few representative sounds. This is the sane path for Crucible.

Translation Notes

  • Steam/fire/acid: mostly noise, shaped by highpass/bandpass filters.
  • Sparks/electricity: short tone sweeps plus a little noise transient.
  • Glass: multiple inharmonic tone partials with a longer decay.
  • Lava/stone: lower frequencies, soft thumps, short filtered noise.
  • Crucible rule: sim emits event counts; audio system decides what is audible.
